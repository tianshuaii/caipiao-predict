# 彩票研究知识库

## 概率论与组合数学

单式大乐透样本空间为 C(35,5)×C(12,2)=21,425,712；双色球为 C(33,6)×16=17,721,088。公平独立开奖下每个合法组合等概率，历史冷热、遗漏长度都不改变下一期概率。同一期 5 注完整组合去重可避免重复覆盖。

从 N 个号码中固定选 k 个，开奖也选 k 个，命中 X 个号码服从超几何分布：P(X=x)=C(k,x)C(N−k,k−x)/C(N,k)。前后区独立时相乘得到命中组合概率；同一区内各号码不独立，不能把边际概率直接相乘当作整注概率。条件概率 P(A|B)=P(A∩B)/P(B)，跨期独立假设下 P(下一期|历史)=P(下一期)。复式只是购买多个组合，比较时必须统一成本。

## 统计推断

在看结果前固定主指标、候选数量、检验方案和训练窗口。当前主指标是逐期开奖的平均边际 Brier 分数（越小越好），候选对随机基线做逐期配对比较，两项比较采用 Holm 校正。小样本、序列依赖及反复试验都会影响显著性，回测结果仅作探索。

置信区间描述估计量的不确定性，不代表下一期落入区间的概率。当前随机模拟区间是 200 次等预算随机投注的平均命中数参考分布，不是“模型提升”的置信区间。若要正式升级模型，应预注册最小有意义的 Brier 改善量，根据逐期差值方差估计所需样本量，并进行独立前瞻验证。头奖极稀有，不能用几次中奖估计稳定优势。

## 数据处理

原始响应先保存再解析；每条结果携带来源、时间、解析版本和哈希。0 是已知值，空值是未知；带条件的派奖金额不能当作基本奖金。号码冲突阻断预测，主来源更正保留历史版本并重新结算。完整性同时检查首期、年份、年内连续性以及成功全量分页保存的期号清单。

## 实验与回测

按时间滚动：每个目标期仅使用之前的数据；前瞻正式预测与历史回测分表保存。当前训练最多 300 期，暖启动 160 期，最后 30 期用于概率校准，最近 60 期用于初次探索性回测。所有策略每期 5 注、10 元，记录成本、确认奖金、待结算、净收益、Brier、命中数和随机模拟参考区间。不得把官方日后更正的数据快照误称为历史当时可见信息。

## 机器学习

候选为带先验平滑的历史频率模型，以及 L2 正则化逻辑回归（30/100 期频率、上期出现特征），使用独立时间段做 sigmoid 概率校准。正则化减少但不能消除过拟合。校准后约束各区边际概率之和等于选球数；加权不放回抽样只是一种组票策略，不等于恢复了准确的联合开奖分布。均匀随机是正式策略，候选不得凭单次盈利自动晋升。
