# 前瞻评估与自动策略切换

目标：复用 frequency/logistic 模型，每次正式预测时同步冻结候选概率、5注号码、种子、数据快照、代码/依赖版本。已开奖或过销售截止期不得创建前瞻记录；历史回测不计入晋升。

选择：每期影子预测 + 持续证据门槛。替代方案“每月回测赢家直接上线”容易过拟合；“仅人工切换”不能完成自动闭环。保留现有技术栈与服务器。

开奖后按当前无冲突官方版本计算候选和均匀基线的边际 Brier 分数、命中、模拟奖金；更正保留旧评分并以当前版本重算。正式预测不可修改。

统计规则：每彩种对每个代码/依赖版本分配 alpha_j=0.05/[j(j+1)]，累计预算不超过0.05。对开奖前固定概率的逐期配对损失差，用可预测界限归一化到[-1,1]，计算四个固定下注率的 Hoeffding e-process 混合。它检验条件平均概率评分优势，支持持续查看；不是整注中奖概率的证明。候选至少60期，累计Brier改善>=1%，最近30期更优，e值>=1/alpha_j才能晋升。旧模型证据不再满足晋升门槛、最近30期比基线恶化>=1%、版本失效或运行异常时回退基线。跨彩种分别控制，不声称全项目5%错误率。

保存每次选择及理由；只影响随后新建的预测。已有预测只补充尚未开奖的影子记录。样本/版本变化从新的候选组收集，不拼接旧证据；新版本消耗新的预算。

前端策略实验室增加正式策略、候选样本数、评分、证据门槛、晋升条件和切换记录。通知使用真实策略说明。候选失败不得阻塞正式随机预测或核奖。

测试：禁止回填、重复执行幂等、官方更正/冲突、未达标不切换、充分证据晋升、退化回退、异常回退、历史预测冻结、非随机重放、UI构建、迁移后公网检查。

统计依据：Howard et al., Time-uniform Chernoff bounds via nonnegative supermartingales, https://arxiv.org/abs/1808.03204 。本项目实现的是保守有界配对损失混合检验，原假设为候选每期给定过去的信息后的期望评分不优于均匀基线；不把阈值当成中奖概率。有效性依赖开奖前冻结、概率合法和评分数据正确；小的真实优势可能需要远多于60期才能检测。

评估命令仅补充已有未开奖正式预测的候选，不新建正式预测。候选训练完成后再次检查截止时间，保存真实完成时间；正式预测也在训练后复查销售截止。
