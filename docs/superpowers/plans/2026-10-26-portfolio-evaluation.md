# 整组目标与同期随机对照（仅本地）

用户已授权落实此前四项建议。正式推荐、晋升门槛、通知预算不变。

1. 新增独立对照表，每彩种每期100组×5注，开奖前冻结种子与号码，重试不改写；不得给已开奖期补造对照。
2. 新增按开奖指纹保存的对照评分，任何奖/一等奖按整组是否至少命中一注统计。奖金缺失不当作零；未知净收益不参与完整收益比较。
3. 候选版本及正式建议分别按规则版本汇总。对照比较仅使用双方同一期且有效的数据，各随机组跨期累计后展示中位数及2.5%–97.5%分位范围（随机对照离散程度，不是置信区间）。不把100组视作100倍开奖样本。
4. 前端展示独立目标、期数、成本/收益/ROI、同期对照。前瞻晋升仍由原有Brier门槛决定。
5. 先写隔离测试验证防泄漏、幂等、官方更正、规则分组及公平对比；运行全套回归和前端构建。不部署、不推送。
