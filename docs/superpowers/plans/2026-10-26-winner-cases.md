# 一等奖中奖彩票公开案例库

按用户已确认的建议实施。独立于选号、晋升、正式预测和微信通知。

- 来源：官方体彩/福彩中奖报道，URL白名单。默认来源列表发现文章，另支持明确URL导入；限制单次抓取数量，原始响应入RawFetch。
- 一篇报道可对应多个案例，以文章URL+相关段落证据哈希去重。转载/不同文章可能重复，不把案例数当作独立中奖票数或全量分布。
- 保守抽取：只接受同一段落明确的单一彩种、期号、一等奖和票型；区分单式注数、倍投、复式规格、胆拖描述。缺失字段null，不由一等奖注数推断投注注数；模糊信息保留原文并标待核对。
- 保存文章标题、发布日期、来源、抓取时间、证据段落、图片URL及提取版本。图片不自动OCR，不冒称已核对图片。
- 前端独立案例页，按彩种展示、票型筛选、分页、原文链接及证据。不展示获奖者个人身份资料，不推断其完整消费。
- 测试字段区分、未知处理、多案例、无关文章拒绝、URL限制、幂等、API筛选与迁移。真实抓取验证后本地入库，当前新增功能先不自动部署。
