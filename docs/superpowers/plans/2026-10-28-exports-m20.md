# T26 研究报表与导出

沿用executing-plans与TDD，执行已批准路线，本地修改。
- [x] 只读报告聚合：数据质量、四目标当前候选排行、规则绩效、前瞻随机对照、最新历史实验及已存统计检验。
- [x] 生成时间、各来源截止、协议版本、开奖修订清单与报告内容SHA256；缺失与未知不省略。
- [x] JSON/Markdown从同一对象生成，页面预览及下载，刷新才重建；不增加通知或定时任务。
- [x] API和指标一致性/未知/损坏统计报告测试，前端构建、独立审查及文档。

Ruling: 报告为即时只读导出，下载保留快照，不新建数据库表或服务端归档。统计报告保持自己冻结样本，不伪装为当前窗口；没有报告明确不可用。原始响应、环境配置、错误明文不导出。JSON全指标，Markdown摘要后附完整JSON，防止隐藏不确定性。
