# 历史开奖查询与质量看板

入口为「开奖档案」。顶部彩种切换会重建查询状态并回到第一页；点击「查询」应用表单条件并回到第一页，输入过程不会立即发送请求。「重置」清空全部条件，「重新加载」重试数据及质量请求。

## 查询

只读接口示例：

```text
GET /api/draws?game=ssq&issue_from=2026001&issue_to=2026120&date_from=2026-01-01&date_to=2026-10-22&conflict=false&limit=20&offset=0
```

期号为七位数字字符串；期号和开奖日期均为闭区间，所有条件使用AND组合。`conflict`省略为全部，true为有冲突，false为当前未标记冲突。期号/日期倒序、非法格式和无效日期返回422。total与列表使用相同筛选，按期号倒序排列；每页20条，后端最多100条。没有匹配项显示明确空结果，不把它当成全库没有数据。

## 质量口径

质量卡片使用既有 `/api/data-quality`，是当前彩种全库汇总，不受查询条件影响。展示已保存期数、范围、官方清单核验、覆盖状态、冲突期数、奖金完整/不完整期数、缺失年份及最多100个缺失期号。

缺失计数包含整年缺失项，不能解读为精确缺失开奖总期数。识别不到缺口不等于已核验完整。奖金未知保持未知，页面显示待公布，不填零。

数据时效展示最新保存开奖日期、最近新增观测时间和距该观测的小时数。观测不是每次抓取的心跳；相同内容再次抓取可能不新增观测。该时间差不单独判断官方最新应开奖期是否已入库，避免休市或未变化数据的误报。

## 来源与修订

展开每期开奖可查看各奖级奖金、中奖注数、销量、奖池、规则及原始公告。档案页还按需读取 `/api/draws/{game}/{issue}` 的留存观测：来源、时间、原始响应ID、当时号码、奖级奖金、冲突标记及对应公告。

当前修订版本与历史观测分别展示；观测序号不是官方修订编号。此前没有保存的观测不会伪造，历史冲突标记保留原貌。本页面没有修改、重新采集或解除冲突入口。

手机端筛选纵向排列，宽表在自身容器内横向滚动。请求在换页、改条件、换彩种或卸载后取消，并阻止旧响应更新当前页面。
