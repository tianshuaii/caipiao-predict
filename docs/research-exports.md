# 研究报表与导出

「研究报表」页面按彩种读取当前指标，一次生成JSON与Markdown。重新读取前两种下载共用同一份内容，文件名带内容哈希前12位。完整SHA256针对data对象的UTF-8紧凑JSON（键排序、ensure_ascii=False），可独立核验。

GET `/api/research/export?game=ssq|dlt` 返回 report、json、markdown。只读，不保存服务端归档、不训练、不采集、不通知；下载文件由用户留存。报表生成时间为UTC，含导出版本及当前代码SHA256。

内容：当前修订开奖期号/日期截止、评估目标期截止（可能尚未开奖）、开奖修订/指纹清单、质量统计、四种目标的候选共同窗口排行、按规则与版本分组的前瞻绩效、100组随机对照、最新历史实验摘要、最近可验证且含本彩种的统计报告。SQLite接口显式开启读事务；生产MySQL沿用默认REPEATABLE READ读事务，请勿将部署隔离级别改为READ COMMITTED后假定多查询为同一快照。

全部财务与统计指标复用页面服务，未知奖金保持null，失败/排除/不完整样本及区间方法保留。Markdown先给质量、模型比较和绩效摘要，再附同份完整JSON，避免省略细节。

历史实验沿用其自己的截止期、数据模式、协议和哈希；旧实验没有的字段是null。统计检验沿用其原始冻结截止与完整检验族（可能包括两个彩种），不裁剪Holm校正范围，也不把旧检验冒充当前窗口结果。文件损坏/格式错误列入unreadable，不参与报告；无可用报告明确unavailable。

导出不包含原始HTTP响应、环境配置、通知正文或错误明文。报告是研究指标快照，不是完整数据库备份；不承诺仅凭报告重新训练模型或恢复数据库。当前修订历史、前瞻记录、统计冻结样本不能混排，随机分位数不是置信区间。

无需数据库迁移或调度变更。微信晨报和独立监控告警频率均保持原状。
