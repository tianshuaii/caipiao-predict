# 组合模拟

前端「组合模拟」支持双色球和大乐透单式、复式、胆拖。输入以空格/逗号分隔的号码，可选已开奖期号进行模拟结算，留空只计费。后端只读接口：`GET /api/research/combinations?config=<JSON>&issue=<7位期号>`。不保存购买记录，不实际购彩，不参与策略晋升或正式推荐。

config：game为ssq/dlt，kind为single/multiple/banker；front/back为选号（胆拖模式为拖码），front_bankers/back_bankers为可选胆码；additional默认为false。所有号码必须为范围内整数，各区不重复，胆码拖码不能重叠。双色球蓝球不能设胆。未设胆的区域可以复式；至少一区有胆码，设胆区总号码须超过本区单式选球数。

每区注数为 C(拖码数, 单式球数－胆码数)，两区相乘。先计算组合数，超过2000注直接拒绝，不尝试展开。单式必须恰好1注，复式至少2注；单式2元，显式大乐透追加3元。暂不支持倍数。

逐注结算复用已有基本单式规则和所选期次公告奖金，保留开奖指纹。冲突开奖拒绝结算，未有开奖返回不存在；中奖金额未知时保留待确认，整组净收益为空。模拟奖金为税前，不含促销派奖。

追加结算独立于正式结算器，仅支持2019019及以后的大乐透：一/二等奖追加部分按公告基本奖金80%向下取整至元，其他奖级不增加奖金；此前期次显式拒绝追加结算。该值是规则推算的模拟值，不是官方追加奖金字段，也不作为实际兑奖凭据。

规则依据：
- [体彩官方大乐透规则](https://m.lottery.gov.cn/ksjz/m/yxgz_dlt/)
- [福建体彩2019版规则介绍](https://www.fjtc.com.cn/2024-04/08/content_31617389.htm)
- [浙江体彩2026规则原文](https://www.zjlottery.com/Notice/UploadFiles_3216/202601/2026011617012553.pdf)
- [湖南省民政厅双色球规则原文](https://mzt.hunan.gov.cn/mzt/fc/xwzxfc/tzggfc/202601/33894962/files/9b6723ae4d8743099b90d5edfe7d39ea.pdf)

结果可展开逐注查看或检查完整JSON。单次配置与结果仅在页面内存中保留；账户、追号和持久流水属于T23。
