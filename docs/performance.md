# T14 模拟绩效口径

新报告协议为 `performance-ledger-v1`，读取T13评估记录。按模式、彩种、正式/候选、策略、规则版本、实验版本分别统计，不将不同版本合成一条资金曲线。前瞻缺少实验hash的旧记录沿用策略版本作为标识；历史新回测保存实验配方hash，均匀基线保存其选号协议版本。旧历史报告不回填。

## 数据与接口

`GET /api/evaluations?game=ssq&initial_capital=1000` 的 `performance` 为全部前瞻记录的分组绩效。`limit/offset`仅分页原始records；`strategies`只筛选共同期comparison，不筛选performance。绩效是各组完整时间线的描述，并非共同期排名。

initial_capital默认1000元；接口接受0至10亿元、最多两位小数。新历史回测使用1000元默认资金，完整绩效写入实验报告及artifact。本轮没有增加前端曲线页面，图表展示在后续前端任务中接入。

## 奖项与金额

- prize_ticket_counts：各奖级中奖注数。同一期两注中同一奖级计两次。
- prize_period_counts：各奖级中奖期数。同一期同奖级最多计一次。
- any_prize_periods、first_prize_periods：任意奖及一等奖中奖期数；对应中奖率以evaluated_periods为分母，奖金尚未知但奖级已核对的期次仍计入。
- periods、evaluated_periods、status_counts：全部记录期数、有效结算期数和各状态数量，防止失败被隐去。
- known_cost、known_return：可确定的成本及奖金。成本不全时cost=null；失败/待结算/未知奖金存在时，完整net、roi及最大回撤均为null。
- ROI=净收益/累计投注成本，零成本时为null；小数0.25表示25%。资金不是投注成本，不能将净收益/初始资金冒充ROI。

## 曲线及回撤

按期号升序，以每期开奖结算后为观测点：

`累计净收益 = Σ(奖金−成本)`

`账面资金 = 初始资金 + 累计净收益`

`历史峰值 = max(初始资金, 此前及当前各期末账面资金)`

`当前回撤金额 = 历史峰值−当前账面资金`

`当前回撤比例 = 当前回撤金额/历史峰值`

最大金额回撤和最大比例回撤分别取全序列最大值，可能发生在不同期。初始资金为零时，本协议不计算比例回撤，金额回撤仍可计算。

失败或奖金未知的第一期及之后，累计净收益、资金和回撤点全部为null，不插值、不将金额补0，也不删除该期后拼接曲线。此前的完整前缀保留，但不冒充全区间最大回撤。待结算补齐后，查询自动恢复完整结果。

资金可为负、比例回撤可超过100%，仅表示固定注数账面模拟；不表示余额不足仍可实际购买。没有税费、追加、融资成本、充值或按余额停买规则，不计算购票扣款瞬间现金低点。

人工案例：初始10元，四期每期成本2元，奖金0/10/0/0；净收益-2/6/4/2，资金8/16/14/12，总成本8、总奖金10、ROI25%，最大回撤金额4、比例25%。

所有指标只用于描述模拟结果，不改变选号、通知或前瞻晋升门槛。
