# 约束选号研究（T12）

登录前端后进入「约束选号研究」，选择大乐透或双色球。前后区可分别限定奇数个数、小号个数、三区/四区计数、和值范围和跨度范围。空白表示不限；双色球蓝球只有一个号码，不支持跨度条件。

小号界限为号码上限整除2；分区索引为 `(号码-1)*分区数//号码上限`。各分区数量之和必须等于该区选球数。条件用于结构研究，不代表提高中奖概率。

每次生成1–10注、最多尝试2000个候选，票组去重。每注按2元显示模拟预算，不实际购买。复用统一均匀选号协议与组合指标；同配置、种子与版本可复现结果。候选种子是初始种子加从0开始的尝试序号。

结果分三种：

- 完成：得到指定数量且全部满足条件的票组。
- 约束无解：必要条件已发生矛盾，说明原因并停止。
- 搜索上限：有限采样没有找到足够票组，不能据此认定无解；展示匹配数量，但不返回不完整票组。

保存按钮将配置与结果一起保存在当前浏览器，两个彩种合计最多20条，可载入及删除。不跨设备同步，清除浏览器数据会丢失记录。服务端持久化留待账号权限模块完成；存储失败或损坏会明确提示，不静默覆盖旧数据。

只读接口：`GET /api/research/selection?config=<URL编码的JSON>`。config包含game、seed、count、pool_size、front、back。未知字段、非法类型及超限参数返回422。响应包含配置、生成及指标版本、候选种子规则、尝试数、匹配数、预算和状态。

研究接口不读取训练历史，不写正式预测或候选评估记录，不改变晨报每彩种5注及策略晋升。
