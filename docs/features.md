# 历史指标服务（M2）

这是历史描述与模型研究接口，不代表下一期中奖概率，也不替代随机对照或前瞻验证。
正式推荐仍为每彩种5注。14种候选使用原特征协议；新增描述指标不会自动加入模型训练。

## 入口

- `GET /api/features/catalog`：所有指标ID、公式、版本、依赖、空值和适用窗口。
- `GET /api/features?game=ssq&zone=front&window=20&cutoff_issue=2026121&as_of=2026-10-26T00:00:00Z`
- 彩种 `ssq/dlt`；区域 `front/back`；窗口 `10/20/30/50/100/500/all`。
- 必填 `cutoff_issue`（包含该期）、带时区的 `as_of`（实际观测时间截止）。实际样本末期另存 `last_issue`，不可把请求截止当作已采集末期。
- 使用历史保留观测，截止范围有已知冲突或当时未留存记录时返回409；参数错误422。
- 纯计算入口 `lottery.feature_service.analyze_features(rows, game, zone, cutoff_issue, window)` 接受调用方提供的数据快照；不负责恢复观测时间。调用方必须先选定数据模式。API使用 `history_as_of`，不会把今天修订的数据冒充过去已知数据。
- 训练/回测经同一模块导出的 `feature_sequence` 继续调用原实现，保持固定种子结果和版本；基础遗漏直接复用原 `omission_features`，展示层将原数值占位转换为 null。

## 返回数据

`numbers` 是每号统计；`combinations` 是窗口内每条记录的组合指标；`cooccurrence` 是非零二码/三码共现。
还包括特征版本、实际样本数、可用记录数、短窗口标记、首尾期号、窗口号码快照哈希以及数据模式。
哈希只描述窗口内被计算区域的期号和号码，不是原始HTTP证据哈希，也不是模型版本。
目录按有明确含义的指标登记，分类数组/交互列不算多个独立指标。

## 计算口径

- 窗口按保留记录数，而非天数；跨年不会重置。尚不能凭记录数证明官方期次完整，没有以虚构记录填补缺期。
- 当前遗漏：最后一次出现后经过的记录数。窗口内未出现时为窗口长度，`left_censored=true`，只代表下界。空历史为null。
- 已完成遗漏：相邻出现位置差减1。不包括窗口左边界至第一次出现、最后出现至窗口末端。最大/平均/总体标准差只统计完成间隔，没有完成间隔则null。重复周期是遗漏+1，并保留次数分布。
- 频率分母为实际样本数；冷热使用竞争排名，并列同名次。频率Z使用理论单号概率k/M，只是描述标准分，不是通过多重检验后的显著性结论。
- 三区/四区使用 `floor((号码-1)*箱数/M)`；分区密度为区内所选号码数除该箱可选号码数。大小界线 `floor(M/2)`，1单列，既非质数也非合数。
- 奇偶/大小连续性：按号码排序后相同标签的最长连续段，不是跨期开奖连续次数。
- 重号/邻号/重尾与窗口内上一条保留记录比较；窗口第一条没有对照，返回null。邻号每个本期号码最多计一次；重尾包含重号。“上期差”是排序对应位置相减。
- AC为互异正差值数减(k-1)。组合熵明确选用尾数分布的Shannon熵（bit），不宣称是彩票随机性检验。
- 单球区的跨度、连号、间隔、同尾号码对、差值数、AC均返回null；均值/中位数仍有意义，方差为0。
- 共现仅列出现过的组合，未列组合次数为0。二码条件分母为给定单号出现期数；三码条件分母为给定另外两个号码共同出现期数，返回各条件分母。统计同期开奖，不是跨期预测。小分母得出的频率1不表示确定性。

本阶段只提供只读API与纯函数，分析页面在T19。没有数据库结构变更、历史预测重写、云端发布或真实微信发送。
