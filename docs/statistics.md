# 统计检验中心

协议 `randomness-center-v1` 对用户提供的冻结历史快照做探索性诊断，不生成选号、不触发策略晋升，不自动运行采集或通知。

从项目根目录执行：

```sh
backend/.venv/bin/python -m lottery.cli statistics /绝对路径/dataset.json --simulations 999 --seed 20261028
# 原脚本入口也可使用
backend/.venv/bin/python scripts/analyze_randomness.py /绝对路径/dataset.json --simulations 999
```

输入 JSON 结构如下（实际每个规则组至少30期才计算）：

```json
{"games":{"ssq":[{"issue":"2025001","draw_date":"2025-01-02","front":[1,2,3,4,5,6],"back":[1]}]}}
```

支持 `dlt`、`ssq`；日期字段也兼容 `date`。期号必须为规范七位字符串，记录按期号递增、日期不倒退，号码必须符合对应彩种且不重复。显式标记冲突的数据或不匹配的规则版本会拒绝。总量最多10000期。程序根据期号派生规则版本，分别分析；每组不足30期记为跳过。

## 固定检验族

每个规则组、每个号码区固定计算七项：

| 名称 | 统计量或理论对照 |
| --- | --- |
| frequency | 单球次数的 Pearson 差异统计量 |
| sum | 和值分布，与无放回组合的精确分布比较 |
| odd | 奇数数量分布，与超几何分布比较 |
| adjacent | 相邻整数对数量，与组合计数分布比较 |
| lag1 | 理论均值中心化、理论方差归一化的绝对滞后一期乘积均值 |
| runs | 和值高低序列的转换次数相对理论期望的绝对差异 |
| drift | 时间前后两半的平均和值绝对差异 |

所有p值均用完整的独立、均匀、不放回开奖序列做蒙特卡洛校准，不直接使用各球独立的卡方渐近分布。前后区分别检验，本版本没有跨区依赖检验。序列检验只连接同一年内期号相邻的记录，不跨缺期或年界；没有有效边时标为不具信息性。双色球单球后区的连号检验也标为不具信息性。

模拟次数范围99–4999，默认999；采用加一法 `(超出次数+1)/(模拟次数+1)`。最低可达p值为 `1/(模拟次数+1)`。同一报告全部彩种、规则组、号码区的检验统一Holm校正，阈值0.05；检验多或模拟少时，数值分辨率可能不足以拒绝零假设。

## 保存与查询

命令输出报告ID。完整快照和报告保存在 `runtime/statistics/<报告ID>.json`，报告ID为文件内容SHA-256。保存快照规范化哈希及输入原始字节哈希，读取时校验完整性。相同输入与参数可复现同一报告。输入目录另输出 `analysis.json` 和 `tests.csv`，会更新已有兼容输出；若输出路径指向输入文件则拒绝执行，避免覆盖快照。

只读接口：

- `GET /api/statistics?limit=20&offset=0`：分页报告摘要。
- `GET /api/statistics/{report_id}`：快照及完整检验结果。

API没有计算或写入入口。本次未增加独立前端页面。旧脚本只兼容调用方式和输出文件名，检验协议及字段以新版本为准，既有历史报告不会自动重算。

## 解释边界

所有报告固定标为 `post_hoc=true`：固定检验族不代表事先登记了数据窗口。Holm仅校正本报告内的检验，不涵盖跨报告、跨窗口挑选。显著结果需要排查数据质量并在独立数据上验证；不显著也不能证明开奖完全随机。异常诊断不等于可提高未来中奖概率。

随机模拟回归测试是有限种子的烟雾检查，不是精确的误报率估计或统计功效研究。
