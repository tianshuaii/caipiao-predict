# 可解释的候选策略排行

在前端「策略实验室」查看「候选策略排行」。可切换 Brier（低优）、整组任意奖比例、整组一等奖比例和模拟收益 ROI（高优）。对应只读接口：

```text
GET /api/rankings?game=ssq&objective=brier
```

`game` 为 `ssq` 或 `dlt`；`objective` 为 `brier`、`any_prize`、`first_prize` 或 `roi`。协议为 `common-prospective-five-v1`，不写数据库、不触发评分或策略切换。

## 比较口径

参与者是该彩种已有预测记录的当前注册候选版本，失败版本也不会偷偷移出参与者集合。旧版本不混入当前排行榜；原有策略汇总仍可查看历史版本。正式建议可能跨策略切换，因此本表不将正式建议作为额外候选。

每个官方规则版本分别比较。只有预测在截止前生成、训练截止期早于预测期、开奖无冲突、评分对应当前开奖指纹、记录为5注且评分成本10元和结果5条、Brier为有限数时才有效。

在所有参与策略有效期号的交集上统计 Brier、任意奖和一等奖；收益进一步只用所有参与策略奖金均完整的交集。任一策略待确认奖金会从所有策略的收益比较中剔除该期，不能将未知奖金填零。各行样本量与预算一致。新增策略可能缩短共同窗口甚至使其为空，这是共同样本比较的代价。

API返回共同期号、奖金完整期号、各期缺少哪些策略，以及无效候选的具体原因；前端可展开查看。没有有效数据时不补造记录。

## 名次与不确定性

- 每个目标至少30个共同有效期才给名次。这是展示门槛，不是统计优势证明或前瞻晋升门槛。
- 值相同共享名次，例如1、1、3；稳定的策略名称排序仅用于并列展示。
- 所有策略均未命中一等奖时，该目标不分名次，显示无法区分。
- 任意奖和一等奖按每期整组至少命中一注统计，并显示95% Wilson区间；不把5注当作5个独立样本。
- Wilson使用独立、固定概率近似，是探索性描述，不是下一期中奖概率区间。零次一等奖不代表真实概率为零。
- 本表未估计Brier及收益的置信区间；完整奖金子集的收益也不能代表未观察到的稀有巨奖尾部。原有整组面板保留同期随机对照和配对区间。
- 排行不做多重比较显著性声明，也不改变原有前瞻样本、改善比例和持续证据门槛。历史排名第一不代表下一期最优。
