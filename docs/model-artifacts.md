# 训练接口与产物（T09）

统一入口为 `lottery.model_training.fit_model(game, history, strategy)`、`calibrate_scores(scores, labels, seed)` 和 `predict_model(trained)`。历史回测与真实前瞻使用同一训练实现；频率、逻辑回归、随机森林、MLP及其特征组合保持原参数。

`fit_model` 返回 `TrainedModel(metadata, zones)`，包含两区估计器、预处理Pipeline、校准器及截止期下一次推断所需的特征上下文。`predict_model` 只对这个固定上下文推断，不加载新开奖、不重新训练，也不保证模型能直接复用于其他期次。

## 时间与追溯

- 最大训练输入窗口300期，基础特征预热30期，最后30期用于校准；训练标签与校准标签按时间分离，目标期无标签进入。
- 保留截断后的期号序列、训练标签期次、校准期次、截止期、选定数据号码哈希、特征方案/版本、随机种子、所有估计器及校准器参数、生成实现指纹、Python/NumPy/SciPy/sklearn版本。
- 输入必须按时间排序且期号唯一；带冲突或部分缺期号标签拒绝。兼容纯数值实验的全无期号输入，但其截止为null，不能充当前瞻证据。真实候选冻结前另外校验所有期号早于目标期。
- 号码数据哈希是训练窗口快照哈希，原始历史证据仍由候选的 `snapshot_path`、`dataset_hash` 引用。无意义的奖金字段变化不改变这个号码快照哈希。

## 存储与重放

未来新候选在历史证据目录下的 `models/` 保存产物，候选 `provenance.model_artifact` 包含内容哈希ID、格式与训练元数据。既有冻结候选直接复用，不补造历史产物。

`lottery.model_artifacts.save_model(trained, directory)` 使用私有临时文件、原子链接及SHA256内容ID，重复保存同一内容不会覆盖旧文件。
`load_model(id, directory)` 只接受64位十六进制ID，拒绝路径穿越和符号链接文件，先验证完整文件哈希、依赖环境、实现指纹，再反序列化。没有模型上传或任意文件加载HTTP接口。

产物使用pickle保存sklearn对象，仅可从本系统控制的可信目录读取。哈希用于检测损坏，不能防御已经能够任意写入可信目录的人。跨依赖版本/实现变化时加载会明确拒绝，不尝试不可靠的自动迁移；应使用原环境/代码重放。更精细的版本登记属于T10。

训练失败、收敛失败、存储失败独立记录在对应候选的error字段中，不计入有效前瞻样本，其他候选继续，正式推荐可回退均匀基线。历史回测共享训练接口但默认不为每期每模型存储产物，避免无意占用大量磁盘；研究程序可显式保存。

## 兼容性

重构前捕获的概率黄金样例覆盖两个彩种、15种策略（含uniform）、160/310期输入。重构结果逐项误差不超过1e-14。原始票组和14种策略身份仍有独立测试。兼容桥只接受这次经验证的实现指纹；后续生成实现或协议变动仍会改变候选身份。已有冻结预测、评分、预算分配未重写。
