# 号码分析与遗漏热力图

入口为「号码分析」。支持两个彩种的前后区、最近10/20/30/50/100/500条或全部保留记录，以及包含本期的截止期号。页面保留本次观测截止时间，窗口/号码区切换使用同一时间；只有点击本页「刷新观测时点」或重新进入页面才更新该时间；工作台自动轮询不改写它。

## 数据与计算

沿用 `/api/features` 的 `as_of`、`cutoff_issue`、`zone`、`window` 参数和 `/api/features/catalog` 指标定义。只使用当时实际留存的观测；缺少当时观测或存在历史冲突时沿用409拒绝计算，不自动退回当前修订数据。页面展示实际样本量、首尾期、短窗口提示、协议及号码快照哈希。

前端只格式化数值和绘制图表，不重新计算遗漏、频率或理论公式。图表数据和明细来自同一个特征响应。热力图颜色仅将后端遗漏值映射为视觉强度。

## 展示内容

- 每号出现频率柱图，虚线为后端提供的均匀入选概率 `k/M`。
- 每号当前遗漏热力图。数值单位是保留记录，不是日历天或已核验连续开奖期。窗口内未出现显示 `≥n`，只表示下界；空样本显示横线。
- 号码明细：频率、当前遗漏、最大/平均完成遗漏、完成间隔数、冷热排名。无完成间隔保留空值，不当成零。
- 和值、奇数数量、小号数量的经验分布和理论分布。和值使用精确无放回组合计数；奇数/小号数量使用超几何分布，小号为≤floor(M/2)。后端返回每个理论支持值的次数、经验频率与理论概率。
- 逐期组合明细按20条分页，包含和值、奇偶比、大小比、三区比、跨度、AC及上一保留记录重号。单球区不适用的指标明确显示空值。
- 指标定义和空值说明直接取自后端catalog。

特征服务新增 `theory`、`distributions` 字段，既有descriptive-v1指标公式未改变。理论数据对所有样本量都可返回，空样本经验频率为null，避免伪装成观测零概率。

## 解释限制

热号、冷号、长遗漏、曲线偏离均是历史描述；本页不输出显著性结论或预测优势，不生成或切换正式号码。均匀独立、不放回是假定的理论零假设，不是由本次数据证明的结论。全部窗口可能跨奖金规则版本，但本页理论只描述选号空间，不比较奖金收益。

本页热力图是各号码当前遗漏强度，不是逐期遗漏矩阵。没有新增采集、模型、通知、写入接口或生产部署。
