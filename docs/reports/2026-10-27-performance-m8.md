# T14 本地验收：完整模拟绩效指标

新增performance-ledger-v1纯统计模块，按模式/彩种/正式候选/策略/规则/实验版本隔离。提供各奖级注数与中奖期数、任意奖/一等奖中奖率、成本、奖金、净收益、ROI、累计净收益/资金曲线和最大金额/比例回撤。

接入 `/api/evaluations` 的performance字段，initial_capital默认1000元，可通过只读参数修改；新历史回测报告也保存绩效。保留T13原始状态与数据；缺失后曲线断开，不将缺失填0或悄悄排除。原有选号与晋升函数未修改。

## 验证

- 新增12项测试，初次缺模块及集成字段时失败，实施后通过。
- 修复审查问题后，后端完整203项测试通过（57.54秒），7项既有依赖弃用提示。
- 人工核算：初始10元，四期成本各2元、奖金0/10/0/0；总成本8、奖金10、净收益2、ROI25%；权益8/16/14/12，最大回撤4元/25%。
- 覆盖未知奖金保留一等奖、失败不冒充0收益、零成本ROI为空、初始0元比例回撤为空、非法初始资金拒绝、分组及重复期拒绝、只读API与历史报告接入。
- 未修改前端代码，本轮不重复前端构建或浏览器交互验收；前端曲线展示由后续任务接入。

独立审查发现原始零注已结算记录cost=None导致异常，去除测试中的cost手工修补后复现；修复记录构造，使零成本与失败成本未知区分，回归通过。另验证金额和比例最大回撤发生于不同期，以及负权益导致比例超过100%。

## 决定和边界

1. 回撤按开奖期末资金计算，峰值包含初始资金；不含购票扣款瞬间低点，可能小于实际过程现金缺口。
2. 遇到缺失后完整曲线/收益/回撤保持未知；需要补齐数据才能恢复，不用删期改善指标。
3. 初始资金改变权益与比例回撤，不改变选号与注数；账面允许为负，不代表真实可持续投注。资金不同的报告不可直接比较比例回撤。
4. 每个规则/版本独立从初始资金开始，未将跨版本表现拼接成实际账户轨迹。

只修改本地，未访问业务库、未迁移、未发送通知、未部署云端。
