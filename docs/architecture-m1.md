# 模块接口与迁移边界（T02）

本轮保留现有技术栈与API。下面是本轮接口和后续模块的演进协议，不表示所有模块已经迁移。

| 模块 | 输入 → 输出 | 数据/版本责任 |
|---|---|---|
| 数据与规则 | 彩种、期号、可见时点 → 来源观测/标准开奖/质量标记 | 原始响应与观测追加保留；规则以期号确定，未知奖金保留None |
| 特征 | 有序历史、截止期、窗口、特征方案 → 特征矩阵及定义版本 | 禁止目标期泄漏；页面与训练后续统一复用 |
| 模型 | 历史特征与标签、训练/校准段、参数 → 号码边际 | 当前频率/逻辑回归/RF/MLP共用接口；模型产物注册后续T09 |
| 选号 | 彩种、概率/权重、数量、种子、抽样版本 → 合法票组 | 保留uniform-v1和现有weighted实现，不伪称精确实现入选边际 |
| 结算 | 标准开奖、合法单式票 → 命中、奖级、金额、规则版本 | 四条调用链共用；汇总保持各自兼容响应 |
| 评估 | 开奖前冻结记录、对应开奖修订 → 逐期评分与对照 | 历史回测与前瞻不能互相充样本；收益未知期显式标注 |
| 调度 | 时间窗口/任务类型 → 调用编排与日志 | 不自行实现选号或结算；通知与分析分离 |

## 兼容与证据

原GET接口、票组、种子、金额字符串、时间UTC表示和正式推荐5注保持；新增能力使用新端点。数据库改动增量迁移，不重写预测和评分。固定生成协议与已有版本映射用于这次迁移保留身份，协议变化不得使用旧身份；模型证据与结算规则版本是不同维度。

历史观测时点使用服务端保存时间，不拿开奖日期/文章日期推断当时已采集。模型训练完整重放、源码归档、可配置特征、复式与鉴权不在M1内冒充已实现。
